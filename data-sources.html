Raw data sources

Every file under data/raw/ is a public source file exactly as downloaded; the pipeline never modifies it. Five trade-barrier files are not distributed with the repository (two for size, three because their source terms do not allow redistribution); the pipeline ships their derived products in data/interim/ instead, as described in Files not distributed and their derived products. This page lists each file with its source, download location, vintage and whether an account is needed to download it. Which script reads each file and how to bring in a new vintage is in Updating raw data; the original source list is kept as data/data_source.md and the attribution lines in data/raw/README.md.

Each source’s terms of use apply to its files; the project does not relicense them. The terms are linked in the last column of each table.

Files are grouped by role in the pipeline. “Account” says whether the source requires registration to download the file.

Files not distributed and their derived products

Five inputs of scripts 22 and 23, all under data/raw/trade_barriers/, are not distributed with the repository and are listed in .gitignore. Two exceed GitHub’s file size limit; three are extracts whose source terms (UNCTAD TRAINS via WITS, WTO Tariff and Trade Data) do not allow redistribution. In their place the repository tracks the derived products in data/interim/, and main.R reuses those when the raw files are absent. The raw files are needed only to rebuild the derived products from scratch.

Raw file Source Why not distributed Derived file shipped in data/interim/ Consumed by How to obtain the raw file
tariff_ave_WITS_2023.csv World Bank WITS, UNCTAD TRAINS: MFN applied tariffs, 2023 or last observed Source terms tariff_ave_region.csv, export_taxes_comm_reg.csv 22_compute_tariff_ave.R WITS manual query for year 2023 (below)
tariff_ave_2014_WITS.csv World Bank WITS, UNCTAD TRAINS: 2014 applied tariff AVEs Size (about 245 MB) and source terms NTM_IMP_ave_region.csv, NTM_EXP_ave_region.csv 23_compute_NTM_ave.R WITS manual query for year 2014 (below)
ag_hs_products.csv World Bank WITS, product group WTO_HS_Aggri Source terms NTM_IMP_ave_region.csv, NTM_EXP_ave_region.csv 23_compute_NTM_ave.R WITS: export the product group WTO_HS_Aggri as CSV with a Product column of HS6 codes
ag_tariff_USA_2014.xls WTO Tariff and Trade Data: United States applied MFN schedule, 2014 Source terms commodity_hs6_mapping.csv (the commodity-to-HS6 mapping, 67 HS6 codes) 23_compute_NTM_ave.R https://ttd.wto.org/: export the United States applied MFN schedule for 2014 to Excel; sheet Applied_MFN, HS6 codes in column E from row 6
BACI_HS92_Y2014_V202401b.csv CEPII BACI, HS92, release 202401b (the 2014 file of the archive) Size (about 460 MB) NTM_IMP_ave_region.csv, NTM_EXP_ave_region.csv 23_compute_NTM_ave.R scripts/fetch_large_raw_data.sh --download downloads the release archive (about 2.4 GB, resumable) from https://www.cepii.fr/DATA_DOWNLOAD/baci/data/BACI_HS92_V202401b.zip and extracts only the 2014 file

The NTM outputs NTM_IMP_ave_region.csv and NTM_EXP_ave_region.csv are shipped in data/interim/ in the same way as the other derived files; the project owner is obtaining them.

Without arguments, scripts/fetch_large_raw_data.sh (or scripts\fetch_large_raw_data.bat) reports which of the five files is present and prints how to obtain the missing ones. Only the CEPII file can be downloaded by the script; the WITS and WTO files require a free account and an interactive export.

WITS manual query. Sign in at https://wits.worldbank.org/, open Advanced Query, Tariff and Trade Analysis (TRAINS). Reporters: all; partners: all; products: all HS6; year: 2014 or 2023; indicator: AVE of applied tariff. Export the result as CSV and save it as data/raw/trade_barriers/tariff_ave_2014_WITS.csv or data/raw/trade_barriers/tariff_ave_WITS_2023.csv. The file must have the WITS export layout (Reporter, Product, DutyType, Simple Average, Tariff Year); only DutyType == "MFN" rows are used. ag_hs_products.csv is the WITS product group WTO_HS_Aggri exported as CSV with a Product column of HS6 codes.

WTO schedule. ag_tariff_USA_2014.xls is the WTO Tariff and Trade Data export of the United States applied MFN schedule for 2014 (sheet Applied_MFN, HS6 codes in column E from row 6). Script 23 reads it only to build the commodity-to-HS6 mapping: when the file is present the mapping is rebuilt and data/interim/commodity_hs6_mapping.csv is rewritten; when it is absent the shipped mapping is read instead.

What happens without them. main.R runs script 22 only when tariff_ave_WITS_2023.csv is present; otherwise it prints 22_compute_tariff_ave: SKIPPED (WITS 2023 extract absent) and reuses the shipped tariff_ave_region.csv and export_taxes_comm_reg.csv. It runs script 23 only when BACI_HS92_Y2014_V202401b.csv, tariff_ave_2014_WITS.csv and ag_hs_products.csv are all present; otherwise it prints 23_compute_NTM_ave: SKIPPED (large raw files absent) and reuses NTM_IMP_ave_region.csv and NTM_EXP_ave_region.csv. If a raw input and its derived files are both absent, main.R stops with a message naming the missing files. Everything else in the pipeline runs from the tracked raw files alone.
