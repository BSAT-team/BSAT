BSAT Data Processing Workflow 2025–2034

The data_processing folder turns raw agricultural, macro, trade-barrier, and production-side data into the four CSV inputs the BSAT model consumes. main.R sources the numbered R scripts in dependency order; each script owns one transformation.

Model inputs

The pipeline produces four CSVs that together form the model's complete input set. Each is built by its own independent sub-flow of scripts — assembled separately, but consumed as one. Raw sources feed in from the top; the file each sub-flow produces is on the right.
