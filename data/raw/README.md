# Raw data

Public source files exactly as downloaded, read by the pipeline in `code/processing/`. Nothing in this folder is modified by the project; the pipeline writes only to `data/interim/`, `data/processed/`, and `data/packages/`. Which script reads each file, and how to bring in a new vintage, is described in `doc/updating-raw-data.qmd`; download locations and query settings are in `doc/data/data_source.md`.

Five files under `trade_barriers/` are not distributed with the repository. Two are too large for git: `BACI_HS92_Y2014_V202401b.csv` (CEPII, about 460 MB) and `tariff_ave_2014_WITS.csv` (WITS, about 245 MB). Three are extracts whose source terms do not allow redistribution: `tariff_ave_WITS_2023.csv` and `ag_hs_products.csv` (UNCTAD TRAINS via WITS) and `ag_tariff_USA_2014.xls` (WTO Tariff and Trade Data). The pipeline ships their derived products in `data/interim/` instead (`tariff_ave_region.csv`, `export_taxes_comm_reg.csv`, `commodity_hs6_mapping.csv`, `NTM_IMP_ave_region.csv`, `NTM_EXP_ave_region.csv`) and reuses them when the raw files are absent, so the five files are needed only to rerun scripts 22 and 23 from scratch. `scripts/fetch_large_raw_data.sh` (or the `.bat` twin) reports which of the five are present, downloads and extracts the CEPII file with `--download`, and prints how to obtain the WITS and WTO files from their sources.
